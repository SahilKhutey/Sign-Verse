# Research SLR Baselines (Clean-Room)

This module adds research-oriented SLR baselines inspired by architecture families
seen in public papers/toolkits.

Important:
- Repository `0aqz0/SLR` has no explicit license.
- We do **not** copy code from unlicensed repositories.
- Implementations here are clean-room re-implementations of general ideas.

## Added Baselines

1. `Conv3D` isolated sign classifier
- Model: `ai_models/gesture_recognition/conv3d_model.py`
- Dataset: `ai_models/gesture_recognition/conv3d_dataset.py`
- Trainer: `ai_models/gesture_recognition/train_conv3d_research.py`
- Entrypoint: `training/train_research_conv3d.py`

2. `Pose-GCN` style keypoint classifier
- Model: `ai_models/gesture_recognition/pose_gcn_model.py`
- Trainer: `ai_models/gesture_recognition/train_pose_gcn_research.py`
- Entrypoint: `training/train_research_pose_gcn.py`

## Data Requirements

### Conv3D baseline
- Uses frame-folder manifest:
  - `training-data/video_frames_manifest.csv`
- Generated by:
  - `python training/data_pipeline/video_to_frames.py ...`

### Pose-GCN baseline
- Uses keypoint sequences + labels:
  - `training-data/keypoints/*.npy`
  - `training-data/labels.csv`

## Train Commands

Conv3D:
```bash
python training/train_research_conv3d.py --manifest-csv training-data/video_frames_manifest.csv --seq-len 24 --image-size 112 --epochs 20
```

Pose-GCN:
```bash
python training/train_research_pose_gcn.py --seq-len 60 --feature-dim 225 --epochs 20
```

Dry-run smoke tests:
```bash
python training/train_research_conv3d.py --dry-run
python training/train_research_pose_gcn.py --dry-run
```

## Notes

- These baselines are for research comparison and ablation studies.
- Production inference should continue to use the hardened API model path unless
  a research baseline outperforms and is promoted through evaluation gates.
